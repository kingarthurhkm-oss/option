# 크레아틴 흡수 시뮬레이터

몸무게·키와 운동/식사/크레아틴 섭취 타이밍을 조절하면, 시간대별 크레아틴 흡수량과
체내 로드율을 오차범위와 함께 그래프로 보여주는 웹앱입니다.

> 이 브랜치는 메인 브랜치의 옵션 분석기와 무관한 **독립 앱**입니다.

## 사용 방법

- **휴대폰/PC 공통**: GitHub Pages 주소를 열면 바로 실행됩니다 (설치 불필요).
- 또는 `index.html` 파일을 브라우저로 직접 열어도 동일하게 동작합니다.
  서버나 의존성이 전혀 필요 없는 단일 HTML 파일입니다.

## 기능

| 입력 | 설명 |
|------|------|
| 몸무게 / 키 | 근육량·크레아틴 저장 용량 추정 |
| 섭취 시간 / 섭취량 | 슬라이더로 부드럽게 조절 |
| 식사 시간 | 인슐린에 의한 근육 흡수 증강 반영 |
| 운동 시간 | 혈류·흡수 민감도 증강 반영 |

출력: ① 시간대별 혈중 흡수량(±15% 오차밴드), ② 체내 크레아틴 로드율(누적 오차밴드).

교육·시각화 목적의 약동학 근사 모델이며 의학적 조언이 아닙니다.
